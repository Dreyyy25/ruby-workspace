1. Making the Like file 
    rails g model Like "likeable:references{polymorphic}"

2. Migrating the Like file
    rake db:migrate

3. Adding a User Like 
    user = User.first

    user_like = Like.create(
    likeable: user
    )

4. Updating a User Like
    user_like.update(
    likeable: User.last
    )

5. Deleting a User Like 
    user_like.destroy
